# RocketZip privacy statement

RocketZip does not collect, store or send any personal data.

- **No network access.** RocketZip never connects to the internet. It has no telemetry,
  analytics, crash reporting, update checks, accounts or ads.
- **Your files stay on your computer.** Files are read and written only where you choose,
  for the archive operations you start. Temporary files are created next to the archive
  and deleted when the operation finishes.
- **Passwords** you type for encrypted archives are held in memory only for that
  operation and are never saved.
- **Benchmark** (`rocketzip-cli bench`) runs the 7-Zip or WinRAR programs already
  installed on your computer, locally, if it finds them.
- **Installer** changes are limited to the install folder, Start menu and desktop
  shortcuts, the Explorer right-click menu and Send To entry, the `.zfx` file type and
  (optionally) your PATH. Uninstalling removes them.

Questions: open an issue on the project's GitHub page.
